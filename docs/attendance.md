# الحضور والغياب

1. شغّل migration `004_attendance.sql` بعد ملفات التأسيس السابقة.
2. تأكد من وجود فصل وتسجيل نشط للطفل في جدول `enrollments`.
3. عيّن المعلمة إلى الفصل في `classroom_teachers`.
4. افتح `/attendance`، واختر الفصل والتاريخ وسجّل حالة كل طفل.
5. يحفظ النظام السجل باستخدام مفتاح فريد لكل طفل وتاريخ، ويمكن تعديل الحالة لاحقاً.

الحالات: `present`, `absent`, `late`, `excused`.

ضوابط الوصول في migration:
- مدير الحضانة والمشرف الأكاديمي يقرآن ويكتبان ضمن حضانتهما.
- المعلمة تقرأ وتكتب فقط في الفصل المسند إليها.
- ولي الأمر يقرأ سجلات أطفاله المرتبطين به فقط.
- راجع جميع سياسات RLS واختبرها على حسابات منفصلة قبل النشر.
