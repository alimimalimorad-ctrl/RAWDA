# إدارة الأطفال والفصول — الإصدار 0.3

## ما تمت إضافته
- `/children`: عرض سجل الأطفال والبحث بالاسم أو كود الطفل، وإضافة طفل مع توليد كود متابعة فريد مبدئياً، واختيار فصل اختياري عند التسجيل.
- `/classrooms`: عرض الفصول وعدد الملتحقين النشطين، وإنشاء فصل مع المستوى الدراسي والفئة العمرية بالأشهر.
- ربط التنقل في لوحة التحكم بالصفحتين.

## التشغيل
1. تأكد من تطبيق `supabase/schema.sql` ثم `supabase/002_onboarding.sql` كما هو موضح في README.
2. أدخل بيانات Supabase في `.env.local` وفق `.env.example`.
3. سجّل الدخول وأنشئ حضانة من صفحة الإعداد.
4. أضف الفصول أولاً ثم سجّل الأطفال وألحقهم بالفصول.

## ملاحظات قبل الإنتاج
- كود الطفل المولد في الواجهة عشوائي وليس بديلاً عن مولّد مركزي مع معالجة تعارض وإعادة المحاولة؛ يفضل نقله إلى دالة قاعدة بيانات أو Edge Function.
- إضافة طفل أو فصل تتطلب صلاحيات العضو المناسبة وسياسات RLS فعالة.
- هذه المرحلة لا تنشئ حساب ولي الأمر ولا تربطه بالطفل؛ ذلك يحتاج دعوات آمنة وتدفق تحقق مستقل.
- يجب اختبار الصلاحيات والعمليات في Supabase فعلياً قبل استخدام بيانات أطفال حقيقية.
