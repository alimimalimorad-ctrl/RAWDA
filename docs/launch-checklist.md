# قائمة إطلاق RAWDA

## خدمات خارجية مطلوبة
- [ ] إنشاء مشروع Supabase واختيار منطقة مناسبة.
- [ ] تنفيذ ملفات SQL من 001 إلى 007 بالترتيب في مشروع جديد.
- [ ] ضبط إعدادات البريد والتحقق من البريد وروابط إعادة التوجيه.
- [ ] إنشاء مستودع Git خاص وربطه بـ Vercel.
- [ ] إضافة متغيرات البيئة في Vercel ثم النشر.
- [ ] ربط النطاق وإضافته إلى Supabase Auth URL Configuration.

## اختبار قبول إلزامي
- [ ] إنشاء حساب مدير حضانة وإنشاء tenant جديد.
- [ ] إنشاء حضانتين والتأكد من عدم تسرب بيانات إحداهما للأخرى.
- [ ] إضافة فصل وطفل وتسجيل التحاق الطفل.
- [ ] إنشاء حساب معلمة وربطه بفصل؛ اختبار منعها من رؤية فصل غير مسند إليها.
- [ ] إنشاء حساب ولي أمر وربطه بطفل؛ اختبار عدم رؤية طفل آخر أو حضانة أخرى.
- [ ] تسجيل الحضور والدرس والتقييم والتحقق من ظهورها لولي الأمر المخوّل فقط.
- [ ] اختبار الطباعة على الهاتف والكمبيوتر.
- [ ] تشغيل `npm run typecheck` و`npm run build` ومعالجة أي أخطاء قبل الإنتاج.
- [ ] تفعيل النسخ الاحتياطي ومراقبة الأخطاء وسياسة الاحتفاظ بالبيانات.

لا تُدخل بيانات أطفال حقيقية قبل اكتمال هذه القائمة ومراجعة سياسات الوصول.
